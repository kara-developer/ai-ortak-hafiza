# Yapay zekana ver (Claude Code / Codex / Gemini CLI)

```
Bu klasör bir "ortak hafıza" şablonu (README.md, KURALLAR.md, hooks/, araclar/, talimat/).
Önce README.md ve KURALLAR.md'yi baştan sona oku. Sonra benimle adım adım kur:

1. Klasörü ~/ai-hafiza'ya taşı/kopyala (zaten oradaysa atla). Yol farklıysa her betikteki HAFIZA_KLASORU'nu ona göre ayarla.
2. Hangi yapay zekaları kullandığımı sor. Her birinin talimat dosyasına talimat/ORTAK-BLOK.md'deki bloğu ekle
   (dosya varsa sonuna ekle, mevcut içeriği silme). Ne değiştirdiğini göster.
3. Claude Code kullanıyorsam hooks/claude-settings.json'daki hook'ları ~/.claude/settings.json'a BİRLEŞTİR
   (var olan ayarlarımı ezme), betikleri çalıştırılabilir yap.
4. Cihazlar arası istiyorsam klasörü ÖZEL bir GitHub reposuna gönder; asla açık repo yapma.
5. Hafızaya benim hakkımda 3 kalıcı bilgi yazdırmak için bana sorular sor (çalışma tarzım, onay istediğim işler, projelerim).
6. Test: DURUM.md'ye bir satır ekle, yeni bir oturum açtığımda özetin geldiğini birlikte doğrulayalım.
Şifre/token/anahtarı asla hafızaya yazma.
```
